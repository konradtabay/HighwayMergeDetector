================================================================================
WHAT'S NEW IN v2.0
================================================================================

NEW: Road Type Change Detection
  • Tracks road type transitions (Primary → Motorway Link → Motorway)
  • Adds +15% confidence boost
  • Provides context for ramp classification

NEW: Smart Bounding Box Queries
  • Rectangle-based around start/end points
  • Adaptive buffer: 30% of route distance (1-10km)
  • More efficient for all trip lengths

NEW: Segment-Based Detection
  • Ramps detected as segments (not points)
  • Shows full merge/exit maneuver
  • Start and end coordinates
  • On-ramps use 2x window for complete merge

NEW: Interactive Web Server
  • No HTML generation - all dynamic
  • Dropdown trip selector
  • Live statistics updates
  • Claude AI-inspired design

IMPROVED: Detection Accuracy
  • Better false positive prevention
  • Layered verification approach
  • Mandatory OSM for off-ramps
  • Stricter on-ramp filtering
